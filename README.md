# Maybell – Manual QA Testing Portfolio

## Project Overview

This repository contains my independent Manual QA testing project for the Maybell e-commerce website.

**Website:** https://maybell.in/

**Project Type:** Manual Website Testing  
**Application Category:** E-commerce / Fashion Retail  
**Testing Approach:** Functional Testing and Exploratory Testing  
**Project Status:** In Progress

## Project Objective

The objective of this project is to evaluate the functionality and usability of the Maybell e-commerce website through manual testing.

This project focuses on understanding customer shopping workflows, validating application behaviour, identifying functional inconsistencies, and documenting test results professionally.

## Testing Scope

The following website features are included in the testing scope:

- Homepage and navigation
- Product listing pages
- Search functionality
- Product filters and sorting
- Product details
- Size and colour selection
- Quantity selection and stock validation
- Shopping cart
- Wishlist
- Track Order
- Store Locator
- Basic UI and usability testing

## Testing Activities

- Exploratory testing
- Test scenario preparation
- Test case design
- Test case execution
- Functional validation
- Defect identification and verification
- Screenshot and screen-recording evidence collection
- Test execution reporting

## Tools Used

## Project Deliverables

- Test Plan
- Test Scenarios
- Detailed Test Cases
- Test Execution Report
- Defect Reports
- Test Summary Report
- Supporting Evidence

## Testing Notes

This is an independent portfolio project based on testing the publicly accessible customer-facing website.

Initial observations will be verified before being classified as confirmed defects.

Only genuine, reproducible issues will be documented as defects.
